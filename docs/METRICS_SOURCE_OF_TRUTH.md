# Metrics source of truth

Every number in [`README.md`](../README.md) and [`docs/PRESENTATION_OUTLINE.md`](PRESENTATION_OUTLINE.md), traced to the file in
this repository that produced it. Task A5 in [`docs/TASKS.md`](TASKS.md).

- **Checked against:** commit `e9ae561` (23 Nov 2026).
- **No number was changed.** This file only records where each one comes from.
- **⚠ in the Source column** means the number has no source file, or the source file says something different.
  Those rows are raised as separate issues; they are not "fixed" here.
- **Measured** = a program or a test produced it, and the output is in the repo or was re-run for this check.
  **Measured (documented only)** = a document says it was measured, but no raw output is stored in the repo.
  **Estimate** = a planning figure or an extrapolation. **Published statistic** = from an outside source we cite, not
  produced by this project. **Design value** = a constant or setting in the code.
- **Synthetic or real** describes the data behind the number. "Synthetic" data is generated by `data_gen/` and calibrated
  to MoSPI statistics; "real" data is a public dataset. They are never blended.
- Not covered on purpose: team roll numbers, GitHub PR and task identifiers (K1, Y14 and similar), section numbers, and
  licence names. They are identifiers, not metrics, and the roll numbers are personal.
